Python Cheat Sheet

Key syntax, methods, and common patterns organized by learning level.

🟢 Beginner Level (Phases 1–10)
📦 Variables & Types

Python variables are created upon assignment with =.

name = "Alice"     # str (string)
age = 25           # int (integer)
price = 19.99      # float (decimal)
is_active = True   # bool (boolean)
x, y = 10, 20      # multiple assignment

Check type with type(x).

🔄 Conversion & input()

input() always returns a string; convert explicitly.

text = input("Enter age: ")
age = int(text)         # string to int
cost = float("12.50")   # string to float
s = str(100)            # number to string
🔢 Arithmetic & Modulo

Standard math follows PEMDAS rules.

a + b   # addition
a - b   # subtraction
a * b   # multiplication
a / b   # float division (returns float)
a // b  # floor division (rounds down)
a % b   # modulo (remainder: 10 % 3 = 1)
a ** b  # power (2 ** 3 = 8)
🧵 Strings & Slicing

Slice with [start:stop:step] (stop is excluded).

s = "Python"
s[0]       # 'P'
s[-1]      # 'n' (negative index)
s[0:3]     # 'Pyt'
s[::-1]    # 'nohtyP' (reverse string)
len(s)     # 6 (character count)
"th" in s  # True
🎨 String Methods & f-strings

Strings are immutable; methods return brand new strings.

s.lower() / s.upper() / s.title()
s.strip()               # remove surrounding whitespace
s.replace("old", "new") # replace substring
s.split(",")            # returns list of substrings
"-".join(["a", "b"])    # 'a-b'
f"Cost: ${price:.2f}"   # 2 decimal places
🌿 If, Elif, Else

Evaluate branches using 4-space indentation.

if score >= 90:
    grade = "A"
elif score >= 75:
    grade = "B"
else:
    grade = "C"

# One-line ternary expression:
status = "Pass" if score >= 70 else "Retry"
🔵 Core Level (Phases 11–18)
🔁 For Loops & range()

Loop over sequences and numerical ranges.

for i in range(5):          # 0, 1, 2, 3, 4
    print(i)
for n in range(1, 10, 2):   # 1, 3, 5, 7, 9
    print(n)
for idx, val in enumerate(items, start=1):
    print(f"{idx}: {val}")
⏳ While Loops & Control

Run while condition holds True. Prevent infinite loops!

count = 0
while count < 3:
    count += 1
    if count == 2:
        continue  # skip to next iteration
    if count == 5:
        break     # exit loop completely
📋 Lists (Mutable Sequences)

Ordered, indexed, mutable collections.

nums = [1, 2, 3]
nums.append(4)      # add to end
nums.insert(0, 99)  # insert at index
nums.pop()          # remove and return last
nums.remove(2)      # remove first occurrence of 2
sorted(nums)        # returns new sorted list
copy = nums.copy()  # shallow copy
🔒 Tuples & Sets

Tuples are immutable; Sets contain unique elements.

point = (10, 20)      # Tuple: immutable
x, y = point          # unpacking

colors = {"red", "blue", "red"} # Set: {'red', 'blue'}
colors.add("green")
a | b   # union
a & b   # intersection
a - b   # difference
📖 Dictionaries (Key-Value)

Fast hash-map lookup by key.

user = {"name": "Bob", "xp": 120}
user["name"]            # 'Bob' (KeyError if missing)
user.get("role", "guest") # safe lookup with fallback
user["level"] = 2       # add/update key
for k, v in user.items():
    print(k, "->", v)
⚙️ Functions & Arguments

Define reusable blocks with default arguments and returns.

def greet(name, role="student"):
    """Greeting docstring."""
    return f"Hello {name}, role: {role}"

def total(*args, **kwargs):
    # args: tuple of positional values
    # kwargs: dict of keyword values
    return sum(args)
🟠 Intermediate Level (Phases 19–30)
⚡ Comprehensions

Compact syntax to create lists, dicts, and sets.

# List: [expr for item in iterable if condition]
evens = [x for x in range(10) if x % 2 == 0]
# Dict: {k: v for ...}
sq = {x: x**2 for x in range(5)}
# Set: {expr for ...}
unique_len = {len(w) for w in ["cat", "bird", "hat"]}
🛡️ Error Handling (try / except)

Catch specific exceptions gracefully.

try:
    val = int(input_str)
    res = 100 / val
except ValueError:
    print("Not a valid number")
except ZeroDivisionError:
    print("Cannot divide by zero")
else:
    print("Success:", res)  # runs if no error
finally:
    print("Done cleanup")   # always runs
📁 File I/O & with statement

Always use with open() to ensure auto-close.

# Reading
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()

# Writing / Appending
with open("log.txt", "a", encoding="utf-8") as f:
    f.write("New entry\n")

# JSON
import json
data = json.loads('{"k": 1}')
json_str = json.dumps(data, indent=2)
🏛️ Classes, OOP & Inheritance

Object-oriented programming with constructors & methods.

class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return f"{self.name} makes a sound"

class Dog(Animal):
    def speak(self):
        return f"{self.name} barks!"
🧰 Built-in Functions & Lambdas

High-efficiency Python built-ins.

any([False, True, False])  # True
all([True, True, False])   # False
zip([1, 2], ['a', 'b'])    # (1,'a'), (2,'b')
sorted(words, key=len)     # sort by length
max(students, key=lambda s: s["score"])
square = lambda x: x ** 2
💡 Generators & Clean Python

Memory-efficient generators and clean code tips.

# Generator with yield
def count_up(n):
    for i in range(1, n + 1):
        yield i

# PEP 8 & Type Hints
def calculate_area(width: float, height: float) -> float:
    """Return rectangle area."""
    return width * height
